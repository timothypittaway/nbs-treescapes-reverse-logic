# Reverse-logic method

## Study phases

1. Build the conceptual framework from a baseline case (Murray Park, Alford, Scotland)
2. Identify European NBS repositories systematically
3. Select case studies using adapted PRISMA guidance
4. Categorise community benefits thematically
5. Analyse distribution across biogeographical regions
6. Map vulnerabilities interpretively

## The reverse-logic step (phase 6)

1. Count how often each benefit occurs and where.
2. Find clusters of benefits that point to an underlying vulnerability theme.
3. Infer the community and ecosystem vulnerabilities that would call for that pattern of benefits.
4. Cross-check the inferred vulnerabilities against regional climate and socio-economic stressors.
5. Summarise the drivers of each vulnerability cluster.

## Worked example

A benefit of "reducing urban heat island effects" points to the vulnerability "urban heat and local climate destabilisation", which sits in the Physical/Environment Security cluster.

## Caveat

Inferred vulnerabilities are theoretical indicators. They should be checked against external evidence, such as regional demographic statistics or local health policy, before being used in planning.
